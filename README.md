# IBM HR Analytics Dashboard 📊🧑‍💼

A fully interactive, custom-designed Business Intelligence dashboard built to analyze workforce attrition and HR metrics using the famous IBM HR Analytics dataset. The UI/UX was designed from scratch in Figma to provide a clean, application-like analytical experience.

## 🎥 Visual Proof & Live Demo
Due to the high-resolution rendering of macOS, the live screen recording file size exceeds standard Markdown embedding limits. Therefore, all visual proofs have been neatly organized within the repository:
- **Live Screen Recording:** The complete video demonstrating dashboard interactivity, cross-filtering, tooltips, and reset functions is available as `Recording` inside the `Assets/` folder.
- **Raw Figma Canvas:** All high-resolution, pixel-perfect background canvas designs generated from Figma are also stored in the `Assets/` folder.

## 🔍 Key Business Insights & Features
This dashboard is engineered to provide actionable HR insights:
- **Workforce Overview:** Tracks Total Employees, Active Employees, and the overall Attrition Rate.
- **Attrition Analysis:** Analyzes attrition count by Education Field, Marital Status, and Job Role.
- **Income vs. Attrition:** Visualizes the relationship between salary hikes, average monthly income, and employee turnover.

## 🛠️ Tech Stack
- **Figma:** Custom UI/UX, canvas design, and layout wireframing.
- **Power Query:** Data extraction, cleaning, transformation, and modeling.
- **DAX (Data Analysis Expressions):** Custom measures for calculating Attrition Rate, Active Employees, and dynamic metrics.
- **Power BI Desktop / Service:** Dashboard assembly, cross-filtering, and cloud deployment.

## 📁 Repository Structure
- `Assets/`: Contains all custom Figma background designs and the live demo screen recording.
- `Source_Data/`: The raw IBM HR Analytics dataset (CSV).
- `IBM_Dashboard.pbix`: The main Power BI dashboard file.
- `DAX_Measures.txt`: Complete list of custom DAX formulas used in the project.

## ⚠️ Disclaimer
**Data Source:** The dataset used in this project (`Source_Data/`) was downloaded from Kaggle (IBM HR Analytics Employee Attrition & Performance dataset). It is used strictly for educational and portfolio demonstration purposes to ensure clear data provenance.
